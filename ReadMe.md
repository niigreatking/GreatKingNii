# Machine Learning

A collection of Machine Learning implementations and experiments.

## 📁 Project Structure

- `Gradient_descent.py` – Implementation of Gradient Descent algorithm
- `cost_function.py` – Cost function (Mean Squared Error) implementation
- `Linear Regression` - Implementation of linear regression
- `Neural_network.py` - Implementation of Logistic function to create a neuron and then to neural network.
-`Self_Explanatory_Neuron.py` - Very simplified code for a neuron
